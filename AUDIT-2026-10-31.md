## Method

Work followed the requested diagnosis discipline:

1. Build and run a fast, deterministic, offline feedback loop before hypothesizing.
2. Reproduce the exact symptom and minimize the fixture.
3. State ranked, falsifiable hypotheses before probing.
4. Change one variable per probe and use stateful transport doubles for CAS races.
5. Add the regression at the production boundary, watch it fail, apply the fix, watch it pass.
6. Rerun the focused matrix and aggregate suite, remove debug instrumentation, and record the confirmed cause.

The aggregate runner and redacted logs live outside the repository at `/home/user/stream-recorder-audit/`.

## First pass — 12 defect groups fixed

1. **Brittle archive-filename regression.** Replaced a rotating-backup dependency with an immutable historical fixture.
2. **Truncated public feeds.** Removed RSS/podcast/JSON caps and regenerated committed feeds: 22 recordings, 23 sitemap URLs.
3. **Stale derived feeds after Contents API writes.** The status workflow now regenerates and publishes status, badges, and all public feeds through `safe-push.sh`.
4. **Zeroed/erased system status.** `gen-status.py` refuses unreadable, malformed, wrong-shape, or empty canonical input and preserves the last valid mirror-health summary.
5. **Node feed generation failed open.** Malformed canonical data now fails the production build instead of shipping stale feeds.
6. **Comments POST could overwrite corrupt storage.** Invalid stored JSON/top-level shape fails closed with HTTP 503 and no PUT.
7. **Recorder cleanup deleted unrelated workflows.** Cleanup now queries only `stream-recorder.yml` history.
8. **Wait-for-live used a poll count as a time budget.** The loop now uses a wall-clock deadline, bounds detector passes and sleeps, and validates manual numeric input.
9. **Generic Contents API helper overwrote concurrent updates.** Stale 409/422 payloads are no longer retried with a fresh SHA; ambiguous 5xx responses are re-read before retry.
10. **Sniper drifted from the cookieless public contract.** Defaults now match the recorder: public-only, CDP, cookieless-first; legacy cookie use is explicit opt-in.
11. **Backup retention trusted checkout mtime.** Retention and latest-backup selection now sort by snapshot date in the filename.
12. **High-severity dashboard advisories.** Compatible dependency updates removed all high/critical npm findings; an unsafe ESLint 4 downgrade was rejected.

### Lock regression caught during verification

The first run-identity implementation referenced `$run` in jq without binding it. Free/stale/same-run acquisition failed while busy-owner controls passed. Binding `--arg run "$my_run"` fixed the payload. The expanded nine-case lock matrix passed three consecutive runs.

## Residual risks and limitations

- **Historical secret exposure needs owner action.** Allowlisted commit `8e495b07…` contains a Google API-key pattern in deleted `streams.html` (17 redacted pattern hits). Allowlisting does not rotate, restrict, or purge the key.
- Disposable Mega/Pixeldrain account CSVs are intentionally tracked. Treat them as exposed credentials and rotate/replace if valuable.
- The recording lock remains deliberately fail-open on acquisition errors; duplicate capture is still preferred over a missed stream. Release is ownership-safe and TTL-backed.
- Chat publication now merges on CAS conflict. A deliberate non-conflicting republish still replaces the replay with the newly captured file.
- Nine moderate npm advisories remain.
- Current `actionlint` could not be fetched in this sandbox; available WASM builds were obsolete. YAML, embedded shell syntax, and repository workflow tests passed. CI remains the authoritative actionlint gate.
- Live integrations were not exercised: ffmpeg, bc, SeleniumBase/Chrome, Go, gitleaks, cloud uploads, Discord, YouTube, and GitHub writes. Browser tests used mocks.
- Historical cancelled dispatches and older workflow failures were observed read-only but not root-caused live.
- ShellCheck warning-level findings and ESLint warnings remain nonblocking and were not blanket-suppressed.
